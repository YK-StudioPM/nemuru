Nemuru プライバシーポリシー

最終更新日: 2026年8月11日 ／ 版: v1.0（公開初版）

本プライバシーポリシー（以下「本ポリシー」）は、Nemuru（以下「当方」）が提供するモバイルアプリケーション「Nemuru」（以下「本アプリ」）における利用者情報の取扱いについて定めるものです。

本アプリは、利用者（保護者等の大人）が入力した子どものよびな・今日のできごとをもとにAIが物語を生成し、端末内で読み上げる機能を中心に構成されています。子どもに関する情報を扱うため、当方は取扱いを以下のとおり明示します。本アプリを利用することで、利用者は本ポリシーの内容に同意したものとみなされます。

本アプリは18歳未満の方のご利用を想定していません。 本アプリは、保護者等の大人が、子どものために情報を入力・操作することを前提としています。

2. 利用目的

  1. 物語の生成・保存・表示・再生・削除機能の提供
  2. 有料プラン・無料トライアル・リワード広告視聴に応じた利用制限の管理
  3. 広告の表示（無料プラン利用者のみ）
  4. 不具合の調査、機能改善、利用規約違反への対応
  5. 法令に基づく対応

3. 【重要】入力内容が外部のAIサービスに送信されること

物語を生成するために、当方は以下の情報を Anthropic PBC（米国）が提供する Claude API（claude-haiku-4-5）に送信します。

送信される情報

  • よびな
  • 年齢帯（選択している場合。未選択の場合は送信しません）
  • 今日のできごと（自由入力欄の内容）
  • （プレミアムプランでシリーズ化機能を利用する場合）直近に生成した物語の本文

送信されない情報

  • 利用者ID、氏名（フルネーム）、住所、電話番号、Googleアカウントのメールアドレス（プレミアムプラン購入者を含む）、端末識別子

送信先・処理場所: Anthropic PBC（米国）。日本国外への越境移転が発生します。

保持について: 当方は Anthropic の API 利用条件に基づき利用しており、当方が把握する限り、API 経由で送信された入力・出力は Anthropic のモデルの学習には使用されません。ただし、不正利用検知等の目的で Anthropic 側に一定期間保持される場合があります。詳細は Anthropic のプライバシーポリシーをご確認ください。

利用者の選択: 物語の生成は、利用者が生成を実行した時点で送信が行われます。生成を行わなければ、入力内容が Anthropic に送信されることはありません。

「今日のできごと」の取扱いについて: 入力いただいた内容は、物語の生成にのみ使用され、生成が完了すると当方のサーバー・データベースには保存されず、破棄されます。

4. 読み上げ機能（端末内処理）について

本アプリの読み上げ機能は、端末にインストールされた音声合成エンジン（flutter_tts）により端末内で完結します。読み上げに関する音声データが、当方または第三者のサーバーへ送信されることはありません。

6. 広告について

無料プランでご利用の場合、本アプリはバナー広告（入力画面・履歴画面のみ）およびリワード広告（無料の1日の生成上限に達した後、視聴により追加で物語を生成できる広告）を表示します。

  • 広告は、物語の生成中および物語の表示・読み上げ中には一切表示しません。
  • 広告事業者は、広告のパーソナライズおよび効果測定のために、広告識別子等を用いて情報を取得する場合があります。パーソナライズ広告の可否は端末のOS設定で制御できます。
  • プレミアムプランの利用者には広告を表示しません。

7. 保存期間・データの削除

  • 「今日のできごと」欄に入力された内容は、物語の生成に使用された後、破棄され、当方のサーバー・データベースには保存されません。
  • 生成された物語（本文・タイトル・作成日時・よびな）は、利用者が削除するか、当方がサービスを終了するまで Cloud Firestore に保存されます。
  • 個別の物語は、履歴画面の削除操作でいつでも削除できます。
  • すべてのデータを削除したい場合は、一括削除機能（設定画面）を提供します。削除後の復元はできません。
  • アプリを削除済みの場合など、アプリ内から操作できない場合は、削除リクエストページまたは nemuruappinfo1@gmail.com からご依頼いただけます。
  • プレミアムプランのご購入時にGoogleアカウントを連携した場合の例外については、第8項をご確認ください。連携前に匿名の状態で保存していたデータは、連携後30日間、当方のサーバー内に移行元の記録として保持されたのち自動的に削除されます（この期間も、設定画面の「すべてのデータを削除」により即時削除できます）。

8. Googleサインイン（プレミアムプラン購入時）と匿名認証によるデータ復旧の制限

8-1. 無料でのご利用（匿名認証）

本アプリは、アカウント登録を必要としない匿名認証のみで、無料の機能をすべてご利用いただけます。これは利用者・お子様の個人情報を最小限にするための設計です。

8-2. プレミアムプランご購入時のGoogleサインインについて

プレミアムプランをご購入いただく際は、購入内容を別の端末でも復元できるようにするため、Googleアカウントでのサインインをお願いしています。無料でご利用の間は、Googleサインインを求めることはありません。

  • 取得する情報: Googleアカウントのメールアドレスです。氏名や写真等、Googleアカウントに付随するその他の情報は、当方のシステム上に表示・保存いたしません。
  • 取得の範囲: 本人確認・購入の紐付けに必要な最小限の範囲（メールアドレス）のみで、Googleカレンダー等の追加の権限（スコープ）は一切要求しません。
  • 利用目的: 購入内容の複数端末での復元、および同一のGoogleアカウントで再度サインインした場合の物語データの引き継ぎのみに使用します。
  • 第三者への共有: 取得したメールアドレスを、広告事業者やAIサービス（Anthropic）を含む第三者へ共有することはありません。
  • 既に匿名のまま物語を保存していた状態でGoogleサインインを行った場合、それまでの物語データは新しいアカウントへ引き継がれます。同じGoogleアカウントで別の端末に既にサインイン済みだった場合は、両方の物語データが1つにまとめられます。この際、引き継ぎ元の匿名データは30日間、復旧のための記録として保持したのち自動的に削除されます（第7項参照）。

8-3. データ復旧に関する制約

  • 無料でご利用中（Googleサインインをしていない場合）、アプリをアンインストールした場合、端末を初期化した場合、または端末を紛失・変更した場合、それまでに生成・保存した物語データへ二度とアクセスできません。当方においても、特定の利用者のデータを復旧・再発行することはできません。
  • プレミアムプランのご購入によりGoogleアカウントを連携済みの場合、同じGoogleアカウントで新しい端末にサインインし直すことで、物語データと購入状態を復元できます。ただし、これは連携が完了した時点以降のデータについての救済であり、連携前に既に失われたデータを復旧するものではありません。

大切な物語は、PDF絵本化機能（プレミアム）等を用いて、利用者自身で控えを保存することもおすすめします。

9. 安全管理措置

  • 通信は TLS により暗号化されます。
  • Firestore のセキュリティルールにより、各利用者は自身の匿名UIDに紐づくデータのみアクセスできます。
